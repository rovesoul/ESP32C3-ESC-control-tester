这类项目到底在控制什么

ESC 是 Electronic Speed Controller，中文通常叫“电调”。飞控或单片机并不直接驱动无刷电机三相绕组，而是把“油门意图”发给 ESC，由 ESC 完成换相、闭环或开环驱动、保护和启动逻辑。

对当前项目来说，核心是配网后的本地网页控制台：在浏览器里选择驱动形式、输出 GPIO、频率和占空比，再由 ESP32-C3 输出 ESC 可识别的控制信号。

PWM：兼容性最好 DShot：数字、免校准 RMT：适合精确脉冲 LEDC：适合普通 PWM

协议对比

协议 类型 典型含义 工程判断
PWM / Servo PWM 模拟脉宽 常见 1000us 最低油门，2000us 满油门，周期常见 20ms。 最适合第一版验证。简单、兼容，但常需要油门行程校准。
OneShot / OneShot125 模拟脉宽 比传统 PWM 更短、更快，历史上用于降低飞控到 ESC 的延迟。 现在新项目通常直接考虑 DShot。
MultiShot 模拟脉宽 更短的高低电平脉宽，非常快。 对时序要求高，生态热度已不如 DShot。
DShot150/300/600/1200 数字脉冲编码 16 bit 帧：11 bit 油门、1 bit 遥测请求、4 bit CRC。 现代无人机 ESC 常用。无需校准，有校验，适合用 ESP32 RMT 实现。
CAN / DroneCAN 总线 通过 CAN 总线发速度、状态和遥测。 更适合复杂载具或长线抗干扰场景，硬件和协议栈更重。

PWM：先把电调转起来

普通 ESC PWM 类似舵机信号：周期固定，每个周期中高电平持续时间代表油门。常见范围是 1000us 到 2000us，但不同 ESC 可能支持 1100us-1900us 或更宽范围。

ESP32-C3 上可以用 LEDC 生成 PWM，也可以用 RMT 生成 DShot。当前固件支持在网页里设置 50-1000Hz PWM 频率，也支持 DShot150/300/600/1200 数字油门输出。

很多模拟 PWM ESC 需要做油门行程校准。DShot 的一个重要优势就是不需要这一步。
PWM 波形动画

蓝色短脉冲代表每个周期的高电平。油门越大，高电平越宽。

DShot：数字 ESC 协议

DShot 不再靠“一个周期里的总脉宽”表达油门，而是发送一串固定长度 bit。每个 bit 的总时间固定，1 和 0 通过高电平占比区分。

标准 DShot 帧是 16 bit：11 bit throttle、1 bit telemetry request、4 bit CRC。油门值 48-2047 是有效油门区间，1-47 是特殊命令，0 通常表示停止或 disarm。

DShot bit 流动画

绿色脉冲表示连续 bit。高电平时间长一点是 1，短一点是 0。

DShot 档位 bit 时间 16 bit 帧时间 备注
DShot150 约 6.67us 约 106.7us 速度低，容错相对宽。
DShot300 约 3.33us 约 53.3us 常见折中选择。
DShot600 约 1.67us 约 26.7us 穿越机常见。
DShot1200 约 0.83us 约 13.3us 对硬件和时序要求更高。

放到这个 ESP32-C3 项目里的路线

第一阶段：PWM 版

新增 esc_pwm.c/.h，PWM 用 LEDC 输出，DShot 用 RMT 输出。网页把协议、频率和占空比保存到 NVS，解锁后输出对应 ESC 信号。

这一步最适合快速验证：接线、地线共地、ESC 供电、最低油门和网页控制链路。

第二阶段：DShot 版

新增 esc_dshot.c/.h，用 RMT 发送 16 bit 脉冲序列。RMT 的核心优势是能描述“某个电平持续多少 tick”，正好匹配 DShot 的数字脉冲编码。

等 PWM 链路跑通后，再把输出层抽象成 esc_set_throttle(percent)，底层可以在 PWM 和 DShot 间切换。

调试安全清单

任何 ESC 固件测试、协议切换、油门校准、网页解锁输出测试，都先拆桨。不要相信“只是低油门试一下”。

事项 原因
ESP32 GND 与 ESC 信号 GND 共地 没有共同参考地，PWM/DShot 信号可能无法被正确识别。
先输出最低油门再给 ESC 上电 很多 ESC 会在上电时读取当前油门状态。
限制网页输入范围 输入要做限幅、锁定和默认停机，避免错误参数直接输出危险油门。
给电机控制加 watchdog 或失联停机 如果网页失联或程序异常，ESC 输出应回到安全状态。
